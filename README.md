# Basic Hello World (HTML + CSS)

This repository contains a minimal "Hello, world!" example.

Files:
- `index.html` — the page you can open in a browser
- `styles.css` — basic styles and a toggleable alternate theme

To view:
1. Clone or download the repo.
2. Open `index.html` in your browser.

Optional next steps:
- Customize the text, colors, or fonts.
- Enable GitHub Pages (Settings → Pages) to publish the page at `https://ronnie-berman.github.io/website/`.
